개인정보처리방침

선택한 이미지·영상은 변환을 위해 외부 서버로 전송되지 않습니다.

최종 수정일: 2026년 9월 21일

1. 적용 범위

이 방침은 Morfliq 웹사이트의 현재 기능에 적용됩니다. 이 서비스는 회원가입, 로그인, 결제, 문의 폼을 제공하지 않으며 이름이나 이메일 주소를 직접 입력받지 않습니다.

2. 선택한 파일과 변환 결과

선택한 이미지·영상의 내용, 파일명과 크기는 브라우저에서 읽어 변환 및 화면 표시에 사용됩니다. 영상은 Web Worker와 WebAssembly, 이미지는 브라우저의 이미지 처리 기능으로 기기 안에서 변환되며 파일을 서버에 업로드하는 기능은 없습니다. 실행 로그는 화면에만 표시하고 서버로 전송하지 않습니다.

변환용 작업 메모리는 완료 또는 취소 시 종료됩니다. 화면의 원본 및 결과 미리보기를 위한 브라우저 메모리는 파일 제거, 교체 또는 페이지 종료 시 참조가 해제됩니다. 실제 메모리 반환 시점은 브라우저가 관리합니다. 사용자가 다운로드한 파일은 자신의 기기에 남으며 직접 삭제할 수 있습니다.

3. 사이트 접속과 호스팅

페이지, 스크립트 및 변환 엔진을 불러오려면 호스팅 서비스와 통신합니다. Cloudflare Pages로 운영할 때 Cloudflare는 요청을 처리하고 보안을 유지하기 위해 IP 주소, 요청 시각, 브라우저 정보 등의 네트워크 정보를 처리할 수 있습니다. 이는 영상 내용의 업로드와는 별개입니다. 관련 내용은 Cloudflare 개인정보처리방침을 참고하세요.

4. 쿠키와 브라우저 저장소

현재 애플리케이션은 광고나 분석 쿠키를 설정하지 않고, localStorage 또는 IndexedDB에 영상이나 사용자 설정을 저장하지 않습니다. 브라우저는 빠른 로딩을 위해 일반적인 HTTP 캐시에 사이트 파일과 변환 엔진을 보관할 수 있습니다. 캐시는 브라우저 설정에서 삭제할 수 있습니다. 호스팅 제공자의 보안 기능에서 사용하는 기술은 해당 제공자의 정책을 따릅니다.

5. 광고와 외부 링크

현재 Google AdSense를 포함한 광고 스크립트와 방문자 분석 도구는 설치되어 있지 않습니다. 향후 광고를 도입할 경우 광고 제공업체, 데이터 사용 및 필요한 동의 절차를 실제 설정에 맞게 안내하고 이 방침을 변경합니다. 외부 링크를 열면 해당 사이트의 개인정보처리방침이 적용됩니다.

6. 이용자의 선택

파일을 선택하지 않고도 안내 페이지를 읽을 수 있습니다. 진행 중인 변환은 중지 버튼으로 취소할 수 있으며, 파일 제거 또는 탭 종료로 앱의 파일 참조를 해제할 수 있습니다. 운영자가 영상 파일을 보관하지 않으므로 서버에 저장된 영상 삭제를 요청하는 별도 절차는 없습니다.
