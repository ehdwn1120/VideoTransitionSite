Morfliq 소개

내 파일을 내 기기에서 처리하는 작은 영상 도구입니다.

우리가 만드는 도구

Morfliq은 별도 영상 프로그램 설치 없이 포맷 변환, 오디오 추출, GIF 생성과 해상도 조절을 할 수 있도록 만든 웹 도구입니다. 터미널에서 명령을 실행하는 간결한 경험을 누구나 사용할 수 있는 파일 선택과 설정 화면으로 옮겼습니다.

브라우저에서 처리하는 이유

영상 변환을 위해 파일을 서버로 올리고 다시 내려받는 과정을 줄이고자 했습니다. WebAssembly 기반 FFmpeg가 사용자의 기기에서 실행됩니다. 파일 업로드 API나 원격 변환 서버를 사용하지 않으며 계정을 만들 필요도 없습니다.

할 수 있는 일과 제한

MP4·WebM 등 영상 파일을 MP4, GIF, MP3로 변환할 수 있습니다. 해상도와 품질을 선택할 수 있으며 GIF는 시작 부분의 최대 30초를 지원합니다. 큰 파일과 긴 영상은 데스크톱 프로그램보다 느리거나 메모리 부족으로 실패할 수 있어 입력을 200MB로 제한합니다. 전문 편집, DRM 해제, 손실 없는 복원 기능은 제공하지 않습니다.

기술과 오픈소스

화면은 HTML, CSS, JavaScript로 구성되며 변환 엔진은 ffmpeg.wasm과 FFmpeg를 사용합니다. 엔진을 포함한 정적 파일은 같은 사이트에서 전달됩니다. 브라우저는 처리 과정에서 인터넷 변환 서비스에 영상을 보내지 않습니다.

서비스 운영과 콘텐츠

운영자: ew. 서비스 문의는 문의 페이지에서 안내합니다.

사용 가이드와 포맷 안내는 이 도구에서 실제로 제공하는 설정을 기준으로 작성했습니다. 출력 품질과 처리 속도는 원본과 기기에 따라 달라집니다. 다운로드한 파일을 직접 확인한 뒤 사용하고 중요한 원본은 별도로 보관하세요.

현재 광고, 분석 스크립트, 회원가입 또는 문의 폼은 제공하지 않습니다. 향후 기능이나 데이터 처리 방식이 변경되면 관련 안내와 개인정보처리방침을 갱신합니다.

오류 신고, 기능 제안과 개인정보 관련 문의는 문의 페이지를 참고해 주세요.
