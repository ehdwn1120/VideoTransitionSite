이미지·영상 변환 방법: WebP·JPG, AVI·MP4

원본은 그대로 두고, 필요한 포맷의 새 파일을 만드세요. Morfliq은 브라우저 안에서 FFmpeg를 실행합니다.

1. 시작 전 확인하기

200MB를 넘는 영상은 PC 사용을 권장합니다. 원본 파일은 필요한 부분씩 읽지만 출력과 인코딩 작업에는 메모리가 필요합니다. 1GB 선택 허용이 모든 기기에서 변환 성공을 보장하지는 않습니다.

1GB 이하의 MP4, WebM, MOV, MKV, M4V, AVI 파일을 준비하세요. 확장자가 같아도 내부 코덱은 다를 수 있어 모든 파일의 변환이 보장되지는 않습니다. 다른 메모리 사용량이 큰 탭을 닫고 기기에 충분한 여유 공간을 확보하세요.

2. 파일 선택과 원본 확인

변환기의 점선 영역을 클릭하거나 영상 파일 하나를 끌어 놓으세요. 파일 이름과 크기를 확인하고 원본 미리보기로 내용을 살펴보세요. 브라우저가 원본 코덱을 재생하지 못해 미리보기가 나오지 않아도 FFmpeg가 해당 코덱을 지원한다면 변환할 수 있습니다.

3. 목적에 맞는 출력 설정

  • AVI·WebM → MP4: MP4를 선택하면 H.264 비디오와 AAC 128kbps 오디오로 다시 인코딩합니다. 품질 옵션은 영상에만 적용됩니다. 원본에 소리가 없으면 무음 MP4가 만들어집니다.
  • MP4 → GIF: GIF를 선택한 뒤 길이와 프레임 레이트를 조절하세요. 영상의 시작 부분부터 지정한 길이만 변환합니다. 중간 장면의 시작점은 지정할 수 없습니다. 480p, 10fps, 5초 정도로 시작하면 결과를 빠르게 확인할 수 있습니다.
  • MP4 → MP3: MP3를 선택하면 오디오만 추출합니다. 높은 품질은 256kbps, 균형은 192kbps, 작은 파일은 128kbps를 사용합니다. 오디오가 없는 영상은 실패합니다.

4. 용량과 해상도 줄이기

해상도는 출력 영상의 높이 기준입니다. 원본 비율을 유지하고 선택한 높이보다 작은 영상은 확대하지 않습니다. 세로 영상도 높이 기준으로 축소됩니다.

MP4의 작은 파일 설정은 영상을 더 강하게 압축합니다. 용량을 줄이는 대신 디테일이 손실될 수 있습니다. 원본의 움직임, 길이, 압축 정도에 따라 결과 크기는 달라지며 정확한 목표 용량은 지정할 수 없습니다. GIF는 작은 파일 설정에서 색상 수를 줄입니다.

5. 변환과 다운로드

변환 실행을 누르면 약 31MB의 엔진이 같은 사이트에서 로드됩니다. 이후 선택한 파일을 브라우저 메모리로 읽어 처리합니다. 표시되는 진행률은 FFmpeg의 추정치여서 일정하지 않을 수 있습니다. 탭을 닫거나 기기를 잠그지 말고 완료를 기다리세요.

결과 미리보기와 용량을 확인한 뒤 파일 다운로드를 누르세요. 다운로드 전 페이지를 새로고침하거나 다른 페이지로 이동하면 결과는 사라집니다. 원본 파일은 변경되지 않습니다.

문제가 생겼을 때

  • 엔진 로드 실패: 연결 상태, 콘텐츠 차단 확장 기능을 확인하고 다시 시도하세요.
  • 메모리 부족 또는 탭 종료: 짧은 영상이나 작은 원본을 사용하세요. 입력·출력·엔진이 함께 메모리에 들어가므로 파일 크기보다 많은 메모리가 필요합니다.
  • 출력이 너무 큼: 해상도를 낮추거나 작은 파일 설정을 사용하세요. GIF는 특히 길이와 프레임 수를 줄여야 합니다.
  • 취소: 변환 중지를 누르면 작업과 엔진이 종료됩니다. 설정을 바꾼 뒤 다시 실행할 수 있습니다.

WebP를 JPG로, PNG를 WebP로 바꾸기

WebP 사진이 필요한 앱에서 열리지 않으면 파일을 선택하고 출력 포맷을 JPG로 지정하세요. 원본 크기를 유지하려면 해상도는 원본 유지로 두고, 변환 후 다운로드한 JPG가 열리는지 확인하세요. 투명한 PNG를 웹용으로 바꾸려면 WebP를 선택하면 됩니다. 파일 이름의 확장자만 바꾸는 것과 달리 이미지 데이터를 새 포맷으로 저장합니다.

변환기에 정지 이미지를 넣으면 이미지용 출력 포맷이 자동으로 표시됩니다. JPG는 사진 공유에, PNG는 투명한 로고나 글자가 있는 이미지에, WebP는 웹에서 사용할 이미지에 적합합니다. JPG로 저장할 때 투명 영역은 흰색으로 채웁니다.

해상도는 높이 기준으로 줄이며 비율을 유지하고 작은 원본은 확대하지 않습니다. JPG·WebP의 품질은 높은 품질 92%, 균형 80%, 작은 파일 60%로 브라우저 인코더에 전달됩니다. PNG는 무손실이므로 품질 설정이 없습니다. 결과 용량이 원본보다 커질 수도 있습니다.

파일당 200MB, 이미지당 4천만 픽셀까지 지원합니다. GIF·HEIC·AVIF 및 움직이는 PNG·WebP는 지원하지 않습니다. 원본 EXIF·위치 정보 등 메타데이터는 유지하지 않습니다. 변환 결과의 색상과 화질은 다운로드 전에 확인하세요.

서버에 저장하지 않는 변환기는 어떻게 동작하나요?

Morfliq은 선택한 이미지와 영상을 내 브라우저에서 읽어 변환합니다. 파일을 운영자 서버에 업로드하지 않으며 결과도 서버에 보관하지 않습니다. 파일 다운로드를 누르면 결과가 내 기기에 저장됩니다. 다운로드 전에 탭을 닫으면 결과를 다시 만들어야 합니다.

웹페이지와 변환 엔진을 처음 불러올 때는 인터넷 연결이 필요합니다. 큰 영상의 처리 속도와 성공 여부는 내 기기의 메모리와 성능에 영향을 받습니다. 파일 처리와 사이트 접속 정보의 차이는 개인정보처리방침에서 확인할 수 있습니다.
