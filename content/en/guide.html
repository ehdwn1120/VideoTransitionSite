1. Before you start

Videos: MP4, WebM, MOV, MKV, M4V or AVI, up to 1GB. Images: JPG, PNG or WebP, up to 200MB and 40 megapixels. Support depends on the actual codec, not just the extension.

Use a computer for videos larger than 200MB. The original is read in parts, but encoding and the output still need memory. Large files may fail or close a tab on mobile.

2. Choose a file

Click the file area or drop one file into it. Check the name and size shown below it. The output choices change automatically for images and videos. AVI files and videos larger than 200MB skip source preview; this does not prevent conversion.

3. Choose your output

  • MP4: Encodes H.264 video with AAC audio at 128kbps. Quality settings affect video only. Silent sources produce silent MP4 files.
  • GIF: Converts the beginning of a video, from 1 to 30 seconds. A custom starting point is not available. Try 480p, 10fps and 5 seconds first. GIF has no audio.
  • MP3: Extracts audio. High quality uses 256kbps, Balanced 192kbps and Smaller file 128kbps. A source without an audio track cannot produce MP3.

4. Reduce size and resolution

Resolution limits the output height while preserving aspect ratio. Smaller originals are not enlarged, and portrait videos are also scaled by height. MP4 dimensions are rounded to even pixels for compatibility.

Smaller file quality compresses MP4 more strongly and may lose detail. For GIF it reduces the palette. Output size depends on duration, motion and existing compression; there is no exact target-size setting, and a result can be larger than its source.

5. Convert and download

The first video conversion loads an engine of about 31MB from this site. Keep the tab open and your device awake. After conversion, check the preview and file size, then select Download file. Results are not saved automatically and disappear when you reload or leave.

When a selected file will not convert

Check how far the task got before repeating the same settings. These steps refer to Morfliq's file selection message, progress area and output panel.

1. No filename appears

Close the file picker and try a small JPG or short MP4. If neither appears, reopen the page and select again. If only one file fails, check its extension and size. If it exists only in cloud storage, download it to your device before selecting it.

2. The name appears, but there is no AVI preview

Morfliq skips source preview for AVI and videos over 200MB. If the name and size are visible and Convert is enabled, select MP4 and run it. An AVI extension alone does not tell you whether its internal codec is supported.

3. The engine fails to load

Unlike images, the first video conversion downloads an engine of about 31MB. Check your internet connection and try again. If it still fails, include the displayed error in your support request. Reducing source quality will not fix an engine download failure.

4. The tab closes or reloads during conversion

Memory pressure or mobile background-tab cleanup may cause this, but the symptom alone does not establish the cause. Keep your phone awake and do not switch apps. For a large AVI, try a small source on a computer first. The 1GB limit allows file selection; it does not promise that every device can process a 1GB video. If the tab repeatedly closes, a desktop conversion tool is a better fit.

5. Only MP3 fails

Check whether the source has an audio track. A silent screen recording may have nothing to extract. If the original plays audio but conversion fails, open Show logs and include the last error, source format, output settings and browser in a support request. You do not need to send your private source video.

How to compare your result

A WebP photo gets larger as JPG

Start with original resolution and Balanced quality, then open the downloaded file in the app you need. If compatibility was the goal, a larger file may still solve the problem. To reduce size too, try Smaller file quality and zoom in on text, facial outlines and gradients. JPG fills transparent areas with white; use PNG or WebP for a logo that needs transparency.

You converted AVI to MP4

Open the download in your intended app and check the beginning, middle and end. Check orientation, duration, audio and lip synchronization. Start with original resolution and Balanced quality; compare with 720p and Smaller file if size matters. Portrait video is also limited by height, so check whether small text is still readable.

A GIF is larger than expected

Try 480p, 10fps and 5 seconds first. Five seconds at 10fps is about 50 frames; ten seconds at 24fps is about 240. File size does not scale exactly in that ratio, but this explains why duration and frame rate matter. Use MP4 if you need both movement and audio. Morfliq GIFs start at the beginning of the video; choosing a middle section is not supported.

Changing settings keeps the previous result, but starting a new conversion replaces it. Download each version before comparing another. Keep the original until you have checked the result.

JPG, PNG and WebP images

Select an image, choose the output format and set a height limit if needed. Use PNG or WebP to keep a transparent background, then check the preview and downloaded file. See the format comparison for the tradeoffs.

Image resizing preserves aspect ratio without enlarging the original. JPG and WebP use browser quality values of 92%, 80% or 60%. PNG is lossless, so its quality control is disabled.

Animated PNG/WebP and GIF, HEIC and AVIF inputs are not supported. Original EXIF and location metadata are not retained. Browser processing may change colors; check the downloaded result.

How does conversion without uploads work?

Morfliq reads and converts selected files in your browser. Neither source files nor results are stored on the operator's server. Download the result to keep it on your device; closing the tab before downloading means you will need to convert it again.

An internet connection is needed to load the website and video engine. Conversion speed and available memory depend on your device. See the privacy policy for the difference between media processing and website access requests.

Two small files we tested

On September 29, 2026, we tested synthetic fixtures on macOS arm64 with Node.js 26.7.0, using the site's FFmpeg.wasm core 0.12.10 and conversion settings function. These are engine checks, not phone or 1GB-file performance measurements.

  • WebM to MP4: sample.webm, 11,599 bytes → MP4, 25,079 bytes. A 480p height limit and Balanced quality were used. The result decoded fully.
  • MP4 to MP3: sample.mp4, 16,293 bytes → MP3, 26,478 bytes. Balanced quality (192kbps) was used. The result decoded fully.

Both outputs were larger than their sources. Changing formats does not necessarily reduce file size: source compression and output settings matter. See the test sources.
